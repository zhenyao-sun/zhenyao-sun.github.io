# GTD 用户需求

## 使用与同步

网页面向手机使用，直接连接 Todoist。首次使用时在当前浏览器输入个人 API Token，可在连接设置中清除。各浏览器分别设置，Token 保存在当前浏览器。网页自动载入全部未完成任务，新增、编辑、完成和删除同步到 Todoist。任务数据不写进网站源码或静态文件。

同步失败时保留已有列表或编辑内容并显示错误；不静默丢弃操作，不自动重试写请求。保存失败后重试同一次提交应避免产生重复任务。

## 任务展示与操作

所有任务连续展示，名称、描述、日期和四个维度完整换行显示。日程整行浅蓝，截止整行浅红。编辑用单选下拉菜单，完成用左侧勾选按钮并提供八秒撤销，删除前确认。

## 排序与时段

先按日期从早到晚排序。同一天内，时段和所选地点联动，依次分为四组：

1. 当前时段与所选地点都命中。
2. 只命中地点。
3. 只命中时段。
4. 两个都不命中。

「任意」不算命中；地点按钮选「任意」时，没有地点命中，仍按时段命中及组内规则排列。每组内依次比较以下字段。

- 类型按截止、日程、每年、每月、每周、每日、行动、等待排列。
- 时段：任意、早上、中午、下午、晚上。
- 地点：任意、办公室、良乡家、六里桥、健身房。
- 角色，然后按创建时间和 ID 保持稳定顺序。

例如下午选择健身房，同一天的「下午＋健身房」行动排在「早上＋健身房」截止前面，因为前者所在的匹配组更靠前。同组内，截止排在行动前面，即使截止任务的时段更晚。准确钟点不参与排序，搜索不改变顺序。

北京时间当前时段：11:30 前为早上，11:30 至 13:30 前为中午，13:30 至 17:00 前为下午，17:00 起为晚上。时间边界和跨日自动重新排序，时区固定 Asia/Shanghai。地点按钮记住选择；全部任务始终保留。

## 同类项分隔

日期、时段、地点、类型、角色五项都相同的任务属于同一组「同类项」。当前列表中相邻两条任务只要有一项不同，就在它们之间画一条粗实线。只有一条任务的组也按同一规则分隔，列表首尾无需额外画线。

搜索时，按当前可见的结果重新判断相邻任务并显示分隔线。同组任务仍按创建时间和任务 ID 稳定显示，组内顺序没有优先级含义。

## 任务维度与缺省值

四个维度分别存为 Todoist 标签，每个任务每维恰好一个：

- `角色_`：运动员、数学家、教授、其它。
- `地点_`：办公室、良乡家、六里桥、健身房、任意。
- `时段_`：早上、中午、下午、晚上、任意。
- `类型_`：截止、日程、每年、每月、每周、每日、行动、等待（按排序优先级列出）。

缺少标签自动补其它／任意／任意／行动，缺少日期自动补北京时间今天，并写回 Todoist。保留其他无关标签；旧的 `时间_` 标签转换为 `时段_`。相同维度的多余标签归一为一个有效值。过期日期保持不变。

## 重复任务

每日／每周／每月／每年分别对应 `every! day/week/month/year`，以完成日重新计算下一次。其他类型不重复。重复任务完成后，Todoist 会更新同一任务的下次日期。网络超时后重试完成操作只推进一次日期。撤销重复任务的完成操作会恢复原日期。
